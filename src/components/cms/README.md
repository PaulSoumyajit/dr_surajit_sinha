# Content Management System Components (`src/components/cms`)

This directory houses administrative interface modules for the low-friction back-office publishing workstream (5–8 articles/month).

### Expected Components (Phase 9):
- `AdminNav.tsx`: Navigation bar for authenticated chamber staff.
- `ArticleEditor.tsx`: Split-view Markdown editor with live preview and auto-slug generator.
- `FaqManager.tsx`: Interactive FAQ creation and reordering table.
- `InquiryViewer.tsx`: Encrypted consultation inquiry reviewer with status toggles.
