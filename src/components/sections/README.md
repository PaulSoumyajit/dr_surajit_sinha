# Page Sections (`src/components/sections`)

This directory houses page-specific editorial and interactive narrative sections.

- `HeroSplit.tsx`: Signature 50/50 split hero container (Forest Green card + Architectural motion).
- `ValuePillars.tsx`: 3-column editorial under-hero value propositions.
- `PerspectiveSection.tsx`: "The Sinha Perspective" asymmetric narrative layout.
- `PracticeCarousel.tsx`: Interactive practice domains carousel with `02/04` pagination.
- `ProcessAccordion.tsx`: "A Clear Path, Together" 4-stage horizontal expandable panel.
- `PhotoQuoteBreak.tsx`: Full-width architectural conference room quote break.
- `ScenarioSwitcher.tsx`: "At a Turning Point" 3-scenario selector with synchronized imagery.
- `ChambersCta.tsx`: Chambers photography and closing consultation invitation.
- `CareerTimeline.tsx`: Interactive vertical chronological milestone tracker.
- `BookShowcase.tsx`: Realistic book cover cards with ISBN citations.
- `JudgmentsList.tsx`: Selected reported judgments directory with legal ratio summaries.
- `ConsultationForm.tsx`: Structured consultation enquiry form with Zod validation.
