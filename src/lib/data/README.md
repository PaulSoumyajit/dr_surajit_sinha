# Static Fallback Datasets (`src/lib/data`)

This directory houses verified factual datasets and structured fallback constants, ensuring full offline functionality and compilation safety prior to database hydration.

### Expected Datasets (Phase 1, Step P1-08):
- `profile.ts`: Verified biographical data, court admissions, and client placeholders.
- `practice-areas.ts`: Authoritative descriptions of core legal practice domains.
- `publications.ts`: Authored treatises, monographs, and law review papers.
- `judgments.ts`: Landmark reported decisions with neutral citations and ratios.
- `articles.ts`: Initial editorial essays, reading times, and category tags.
- `faqs.ts`: Standard consultation guidance and procedural FAQs.
